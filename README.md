# 📖 About

This repository provides a **production-ready Selenium Automation Framework** designed using industry best practices. It helps QA Engineers, Automation Engineers, and Software Developers quickly build reliable UI automation with a clean and scalable architecture.

Whether you're learning Selenium or building enterprise automation, this framework provides an excellent starting point.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/imademethink/Automation_Java_Selenium_BDD_Cucumber_TestNG_Reporting_Maven.git
```

---

## Install Dependencies

```bash
mvn clean install
```

---

## Execute Tests

```bash
mvn test
```

---

## Generate Report

HTML reports are automatically generated after execution with failure screenshot attached
